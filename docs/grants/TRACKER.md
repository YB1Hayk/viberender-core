## Честный статус проекта (для ревьюеров)

- Контракты **live на Base Mainnet** (RenderEscrow + JobRegistry, verified)
- **65 тестов** Hardhat, CI на каждый push
- Security hardening завершён в коде: proof-gate (оплатить нельзя без Proof-of-Render), cancel window 3 дня
- **Редеплой hardened-версии** на Base — следующий шаг (после него mainnet-адреса обновятся)
- Эскроу в альфе **символический** (~$0.05) до аудита; оплата — native ETH, ERC-20 в роадмапе
- Живых эскроу-транзакций пока нет (jobCount = 0) — работаем над первыми кейсами

## Что просим финансировать

1. **Аудит смарт-контрактов** (приоритет №1) — перед масштабированием сумм эскроу
2. **Operator CLI** — локальный клиент для GPU-операторов (Docker, автодетект железа, ставит задачу в очередь)
3. **ERC-20 escrow path** — USDC/USDT вместо символического ETH
4. **On-chain индексинг** — события JobRegistry → фронтенд без центральной БД
